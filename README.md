# Students App 📱

An Android application for managing a list of students.
The app allows viewing, editing, and deleting students using a simple and clean user interface.

---

## ✨ Features

- Display a list of students
- Edit student details:
  - Name
  - Student ID
  - Address
  - Phone number
  - Selection status
- Delete a student with confirmation dialog
- Toolbar with back navigation
- Data transfer between screens using Intents
- Modern Android development with ViewBinding

---

## 🛠 Technologies Used

- Kotlin
- Android SDK
- ViewBinding
- RecyclerView
- Activity Result API
- Git & GitHub
